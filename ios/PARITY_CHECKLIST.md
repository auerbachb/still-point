## Release gate decision (Issue #210)

- [x] Feature parity checklist between iOS and web is completed.
- [x] All critical parity gaps are fixed or explicitly deferred with owner/date.

The current release candidate is allowed to ship with the deferred critical gap above because it does not block session completion, account safety, or backend data integrity. The June–July batch (#519–#529) added one net-new unbuilt item (last-used tag #394), which does not block the release gate. The session ratings that batch listed as a web-only gap shipped on iOS in #521 and are being retired under Issue #766: the iOS ratings are retired in 2/4 (#886), the web sliders go in 3/4 (#889), and the server's handling of the old fields in 4/4 (#891). The `focus_rating`/`happiness_rating` columns are kept as legacy data.
